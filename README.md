# HTTP клиент и сервер для сбора информации из интернета

Учебный проект по дисциплине Учебная практика Р

# Описание
Веб-приложение для поиска веб-контента по ключевым словам и сохранения их в LocalStorage для офлайн-чтения

Реализовано взаимодействие клиента и сервера для передачи статуса загрузки в реальном времени

# Функционал
Поиск URL по заданным ключевым словам (javascript, nodejs, react)
Скачивание контента через прокси-сервер с отображением прогресса
Сохранение HTML-страниц в браузере (LocalStorage)
Просмотр сохраненных страниц без подключения к интернету
Обработка сетевых ошибок и переполнения хранилища

# Технологии
Backend: Node.js, Express, Axios
Frontend:  JS, HTML5, CSS3
Протокол: Server-Sent Events (SSE)
